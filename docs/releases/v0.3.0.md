# 书匣 v0.3.0 发布说明

发布日期：2026-08-11

## 版本范围

`v0.3.0` 是管理端、阅读端和后端的统一里程碑。三个仓库必须同时使用 `v0.3.0` 标签，不能混用其他版本。

## 主要变化

- 有声和漫画完成管理员上传、已登记目录扫描、上架、封面及详情管理。
- 有声支持元数据提取、分轨播放、HTTP Range 流式响应和阅读进度。
- 漫画支持图片目录、PDF、ZIP、CBZ 和 CBR 导入、封面提取、分页阅读及增量页面合并。
- 有声和漫画使用独立的 `audio`、`comic` MinIO 桶，也可选择存储管理中已登记且可写的本地/NAS 路径。
- 书籍、有声和漫画支持同一逻辑内容的多个格式；阅读前选择格式，管理员可设置默认格式、人工合并内容或只删除某一格式。
- 内容合并会迁移书架、进度、历史和下载记录；整项删除会清理所有活动格式及关联用户状态。
- 受保护的封面、音频和漫画页面通过短期访问票据读取，前端不直接暴露长期存储凭据。

## 数据库迁移

已有环境升级前必须备份 MySQL，并按以下顺序执行升级包 `migrations/MIGRATION-ORDER.txt` 中的 SQL：

1. `sx-book-audio-comic-storage-foundation-20260804.sql`
2. `sx-book-media-scan-checkpoint-20260808.sql`
3. `sx-book-content-variant-20260808.sql`

SQL 不会由发布包自动执行。执行失败时停止应用升级并恢复升级前数据库备份，不要跳过失败脚本继续启动新后端。

## 部署

正式 fnOS 包输出为 `output/fnos-release-0.3.0`，包含三个 `linux/amd64` 应用镜像、固定版本 Compose、配置、迁移脚本、哈希清单和发布元数据。发布包不包含 `.env`、数据库卷、Redis 数据、MinIO 对象、用户书库或正文文件。

部署和回滚步骤见 [fnOS 持续交付说明](../../deploy/fnos/UPGRADE.md)。

## 已知边界

- 目录扫描不会根据书名、作者、文件名或播讲者自动判断为同一内容，历史重复项也不会自动合并。
- 人工合并时不自动解决相同格式冲突；需要先保留或删除其中一个冲突格式。
- 合并后的标题、作者、封面、分类和标签以管理员选择的目标内容为准。
- MOBI、AZW3 会作为归档格式展示，但当前没有在线阅读引擎。
- CBR 仅保证受支持的 RAR4 单卷、未加密归档；RAR5、加密和多卷归档不属于本版本支持范围。
- 小说保持单一正文来源与追更模型，不进入书籍/有声/漫画的多格式合并流程。
