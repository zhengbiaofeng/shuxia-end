# 有声与漫画测试素材

更新时间：2026-08-04

## 用途与边界

这些素材只用于验证管理员上传、已登记目录扫描、独立存储、上架和阅读端消费链路。它们不属于产品内置内容，也不引入 AI/TTS 功能。

- 有声和漫画只允许管理员上传，或扫描“存储管理”中已登记且业务范围匹配的本地/NAS 目录。
- 有声默认进入独立 `audio` MinIO 桶，漫画默认进入独立 `comic` MinIO 桶。
- 扫描本地/NAS 目录时，页面只能选择“存储管理”返回的合格位置；不能输入任意服务器路径。

## 本机测试目录

测试根目录：

```text
output/test-data/media-import/
├─ audio/夜航札记/
│  ├─ cover.png
│  ├─ 01-departure.wav
│  └─ 02-letter-at-sea.wav
└─ comic/灯塔来信/
   ├─ cover.png
   └─ 第001话/
      ├─ 001.png
      ├─ 002.png
      └─ 003.png
```

`output/` 被 Git 忽略，避免把约 15 MB 的二进制测试素材提交进源码仓库。漫画插图与两个封面均为本次生成的原创测试资产；有声 WAV 由 Windows 本机语音合成器生成，只用于验证媒体链路。

## 重新生成有声样本

在管理端仓库执行：

```powershell
& "E:\code\trae_workspcae\shuxia\qianduan\shuxia-end\scripts\generate-audio-test-fixtures.ps1"
```

脚本源文件保持 ASCII，在运行时解码中文测试文案，兼容 Windows PowerShell 5.1 对无 BOM UTF-8 脚本的旧编码行为。

## 管理端上传验证

1. 进入“内容管理 -> 有声”，点击“上传有声”。
2. 目标存储选择业务范围为“有声”的 `audio` 存储，专辑名填写“夜航札记”，选择两个 WAV 和 `cover.png`。
3. 进入“内容管理 -> 漫画”，点击“上传漫画”。
4. 目标存储选择业务范围为“漫画”的 `comic` 存储，漫画名填写“灯塔来信”，章节名填写“第001话”，选择三张页面和 `cover.png`。
5. 导入内容默认下架；管理员核验封面、顺序和分集/分话后再上架。

## 本地/NAS 扫描验证

1. 在“存储管理”新增两个本地目录，分别将业务范围设为“有声”和“漫画”，并通过可读写校验。
2. 将上方 `audio`、`comic` 目录复制到对应挂载路径。
3. 在有声或漫画管理页点击“扫描目录”，只能看到业务范围匹配、已启用、可写的本地位置。
4. 首次扫描应新增内容；对未变化的目录再次扫描应跳过已绑定的同路径文件。

漫画扫描约定：直接包含图片的目录是一部漫画；下一层文件夹是一话；页面按文件名自然排序；`cover`、`folder`、`front` 或 `封面` 作为封面候选。

## 当前测试限制

- 有声预览代理暂未实现 HTTP Range；播放器会先下载完整受保护音频，再开始播放。当前短 WAV 适合 MVP 验证，大文件上线前必须补流式传输。
- 媒体扫描目前同步执行并受 `maxFiles` 限制，尚未接任务中心暂停/恢复。
- 漫画重复扫描按文件路径幂等；向已导入分话目录追加新页时，当前实现不会合并回原分话，需要在后续增量扫描阶段补齐。
